# OMOP Concept Mapper — User Guide

A lightweight tool for mapping source fields to OMOP concepts. This guide explains how to use the application and complete mappings correctly.

---

## Overview

The OMOP Concept Mapper allows users to:
- Review assigned source fields
- Map each field to OMOP concepts
- Save progress automatically
- Resume work using the same username

---

## Getting Started

### 1. Open the application
Open the Concept Mapper link in your browser (mobile or desktop). No installation is required.

### 2. Enter your username
Enter the username provided to you (e.g. `jane_smith`, `reviewer_2`) and click **Continue**.

> Important: Always use the same username. Your saved mappings are linked to it.

### 3. Select a source field
You will see a list of source fields. Click any field to begin mapping.

- Completed fields show a ✓
- Incomplete fields show a ›

### 4. Fill in the mapping
For each field, complete the following:

- Domain ID  
- Name  
- Concept ID  
- Vocabulary  

Then click **Save mapping**.

The app will automatically move to the next field after saving.

---

## Field Definitions

### Domain ID
The OMOP domain the concept belongs to.
Examples:
- Condition
- Drug
- Measurement
- Observation
- Procedure

---

### Name
The standard OMOP concept name (human-readable label).
